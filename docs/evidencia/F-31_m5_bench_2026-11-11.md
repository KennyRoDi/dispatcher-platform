# F-31: medición M5 de inferencia (2026-11-11)

**Entorno real:** un solo host Windows 11 con Docker Desktop (Docker 29.7.2, Linux), contenedor `python:3.13` (Python 3.13.18, x86_64) con 16 CPU lógicas visibles y ~16 GB de RAM; CPU AMD Ryzen 7 5700X (8 núcleos). No son tres nodos ni WSL2 separados ni hay GPU. Sin otras cargas pesadas deliberadas durante la corrida.

**Versiones:** faster-whisper 1.2.1, CTranslate2 4.9.0, PyAV 18.1.0 (ver `requirements-audio.txt`), psutil 7.2.2; modelo `base` revisión `ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66` (Systran/faster-whisper-base, MIT).

**Audio:** un único clip, `jfk.flac` de https://github.com/SYSTRAN/faster-whisper/blob/master/tests/data/jfk.flac (repositorio MIT; discurso de dominio público), convertido a WAV mono 16 kHz de 11.372 s (sha256 `279974abefa51c5fc8be9d60445157a81239ed8c81265f8f716c302a63069042`). Es inglés: se usó una copia de `config/audio.toml` con `idioma = "en"`; lo demás es idéntico.

**Comando** (ejecutado desde la raíz del repo montada en `/app`):

```bash
pip install faster-whisper==1.2.1 av==18.1.0 psutil
python scripts/measure/m5_bench.py --compute cpu-float32,cpu-int8 --threads 1,2,4 --reps 5 --audio /bench --config /audio_en.toml --salida /bench/m5_bench.json
```

**Salida cruda** (JSON completo en `F-31_m5_bench_2026-11-11.json`):

```
config,latencia_media_s,latencia_p95_s,throughput_x_realtime,memoria_pico_mb,repeticiones
cpu-float32-h1,2.310,2.505,4.922,488,5
cpu-float32-h2,1.611,1.653,7.057,470,5
cpu-float32-h4,1.321,1.367,8.612,519,5
cpu-int8-h1,1.954,2.233,5.821,317,5
cpu-int8-h2,1.049,1.187,10.841,343,5
```

**Limitaciones:** una sola corrida de 5 repeticiones sobre un clip de 11 s (no representa audios de 60-120 s); el contenedor ve 16 CPU lógicas, no los límites de un nodo real; la memoria es RSS muestreado tras cada repetición y todas las configuraciones corren en el mismo proceso (el RSS de una configuración puede arrastrar memoria de la anterior); latencias con hilos > 4 no se midieron. No hay medición de GPU.
